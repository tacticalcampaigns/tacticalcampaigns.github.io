# Tactical Data Hub

Home page for data.tacticalcampaigns.com — the hub for the Tactical Campaigns
data suite: Utah early vote, precinct mail map, race monitor, ballot count
tracker, and influence mapper.

One static `index.html` plus a `CNAME` file and the official logo
(`logo.png`, 600x288 transparent PNG, taken from the Tactical Campaigns
WordPress site). The CNAME file pins the custom domain — do not remove it.
Each dashboard lives in its own repo under the tacticalcampaigns org and is
served at `data.tacticalcampaigns.com/<repo>/`.
